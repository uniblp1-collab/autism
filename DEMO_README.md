# Демо Autism Connect — офлайн-версия для показа

Это **демонстрационная** версия приложения. Она работает **без сервера, без базы данных и без
интернета** (после первой загрузки) — её можно поставить на планшет как обычное приложение и
показывать где угодно, даже без сети.

> ⚠️ **Это только для показа.** В демо нельзя редактировать карточки, нет входа по логину, ничего
> не сохраняется на сервер. Для реальной ежедневной работы ребёнка нужна обычная (серверная)
> версия — это демо её не заменяет.

Что работает в демо: экран ребёнка, разделы, карточки с картинками, листание, озвучивание,
кнопки «Да»/«Нет», расписание, избранное (в рамках открытой сессии).

---

## 1. Как собрать демо

Нужен компьютер разработчика с установленным проектом (как обычно: `pnpm install`). Данные для
демо уже лежат в репозитории (папка `apps/frontend/public/demo-data/`), поэтому **база данных для
сборки не нужна**.

Одна команда из корня проекта:

```bash
pnpm --filter @autism-connect/frontend build:demo
```

Готовые файлы появятся в `apps/frontend/out/` — это обычные HTML/CSS/JS, никакого сервера внутри.

> Для разработчика: команда — это `NEXT_PUBLIC_DEMO_MODE=true next build` (статический экспорт
> Next.js). Если понадобится обновить демо-данные из реальной БД — поднимите Postgres и выполните
> `pnpm --filter @autism-connect/database export-demo` (один раз), затем пересоберите демо.

## 2. Как развернуть PWA на планшете

Планшету нужен интернет **только один раз** — при первой установке. Дальше приложение работает
с иконки полностью офлайн.

> ### ❗ Главное требование: адрес должен быть по `https://`
>
> Чтобы приложение **установилось и работало офлайн**, планшет должен открыть его по защищённому
> адресу (`https://…`). Это требование браузеров к PWA — офлайн-режим (service worker) не
> включается на обычном `http://`.
>
> Поэтому **нельзя** просто раздать файлы по локальной сети как `http://192.168.…:8080` и
> установить оттуда — по такому адресу приложение откроется в браузере, но **не установится и не
> будет работать офлайн**. Нужен `https`-адрес — его бесплатно дают способы ниже.
>
> Ещё демо должно лежать **в корне** адреса (`https://сайт/`, а не `https://сайт/папка/`) — все
> рекомендуемые хостинги так и делают по умолчанию.

Выберите один из двух способов получить `https`-адрес.

### Способ А — быстрая временная ссылка (для разового показа, без регистрации)

Подходит, когда нужно один раз показать демо и не хочется ничего заводить. Ссылка живёт, пока
запущены команды на компьютере; после установки на планшет она больше не нужна.

Понадобится [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
(на macOS: `brew install cloudflared`).

1. Собрать демо (см. §1).
2. В одном окне терминала раздать готовые файлы локально:
   ```bash
   npx serve apps/frontend/out -l 8080
   # или, без установки serve:  python3 -m http.server 8080 --directory apps/frontend/out
   ```
3. В другом окне поднять временный `https`-туннель на этот адрес:
   ```bash
   cloudflared tunnel --url http://localhost:8080
   ```
   Команда напечатает ссылку вида `https://random-words.trycloudflare.com` — это адрес демо.
4. Открыть эту `https`-ссылку на планшете и установить (см. «Установка на домашний экран» ниже).
5. После установки на планшет команды на компьютере можно закрыть — приложение уже скопировано
   в планшет и работает офлайн.

### Способ Б — постоянное размещение (Cloudflare Pages, бесплатно, свой `https`)

Подходит, когда демо нужно надолго и с одной стабильной ссылкой. «Разместить» здесь — это не
«держать сервер», а раздача готовых файлов; `https` хостинг даёт автоматически. Аналогично
работают Netlify и GitHub Pages.

1. Зайти на <https://pages.cloudflare.com> → **Create a project** → **Direct Upload**.
2. Перетащить туда **содержимое** папки `apps/frontend/out/` (файлы внутри папки, не саму папку).
3. Cloudflare выдаст постоянную ссылку вида `https://имя-проекта.pages.dev` — это адрес демо.
4. Открыть ссылку на планшете и установить (см. ниже).

### Установка на домашний экран (после того как есть `https`-ссылка)

1. Открыть `https`-ссылку демо в браузере планшета:
   - **iPad** — только **Safari** (в других браузерах на iOS установки PWA нет).
   - **Android** — **Chrome**.
2. Добавить на домашний экран:
   - **iPad (Safari):** кнопка «Поделиться» (квадрат со стрелкой вверх) → **«На экран „Домой“»** →
     «Добавить».
   - **Android (Chrome):** меню «⋮» справа сверху → **«Установить приложение»** (или «Добавить на
     главный экран»).
3. На домашнем экране появится иконка приложения. **Запускать теперь нужно с этой иконки** — оно
   открывается на весь экран, без адресной строки браузера.
4. Один раз откройте приложение **с иконки при включённом интернете** и дайте ему полностью
   загрузиться (пара секунд) — так оно докэширует всё нужное.
5. Готово: теперь можно выключить Wi-Fi и мобильную сеть (или включить авиарежим) — демо работает
   с иконки без интернета.

### Проверить, что офлайн действительно работает

1. Запустить приложение с иконки.
2. Включить авиарежим (или выключить Wi-Fi).
3. Полистать разделы, понажимать карточки — картинки показываются, озвучивание работает.

### Если что-то не так

- **Не появляется «Установить приложение» / «На экран „Домой“»** — скорее всего адрес открыт по
  `http://`, а не `https://` (см. требование выше), либо на iPad используется не Safari. Ещё
  вариант — страница не догрузилась: обновите и подождите пару секунд.
- **Установилось, но офлайн белый экран** — при первой установке не было сети или приложение не
  успело догрузиться. Откройте его один раз **с иконки при интернете**, дождитесь полной загрузки
  (кэшируется всё), после этого офлайн заработает.
- **Нет озвучивания** — на планшете нет русского голоса (см. §3).

> Быстрая проверка на самом компьютере (для разработчика): `npx serve apps/frontend/out` и открыть
> `http://localhost:8080` — на `localhost` браузер разрешает офлайн-режим без `https`. Но **с
> планшета** так открыть нельзя (localhost — это сам компьютер), поэтому для планшета нужен один из
> способов А/Б выше.

## 3. Про озвучивание

Озвучивание карточек работает средствами самого планшета и **интернет ему не нужен**. Но нужен
установленный на планшете **русский голос**. На большинстве современных планшетов он есть.

Если русского голоса нет — при запуске демо покажет сверху жёлтую подсказку («на этом устройстве
не найден русский голос…»). Само демо при этом продолжит работать, просто карточки не будут
проговариваться. Как правило, русский голос ставится в настройках планшета
(*Настройки → Специальные возможности → Синтез речи* или *Настройки → Язык → Голосовой ввод/TTS*).

## 4. Коротко

| Шаг | Действие |
|---|---|
| Собрать | `pnpm --filter @autism-connect/frontend build:demo` → папка `apps/frontend/out/` |
| Получить `https` | Способ А: `cloudflared tunnel --url http://localhost:8080` (временно) · Способ Б: залить `out/` на Cloudflare Pages (постоянно) |
| Установить | Открыть `https`-ссылку на планшете → «Добавить/Установить на домашний экран» |
| Прогреть кэш | Один раз открыть с иконки при интернете, дождаться загрузки |
| Пользоваться | Запуск с иконки, интернет не нужен |
