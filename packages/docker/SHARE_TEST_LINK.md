# Как дать временную ссылку на приложение для теста

Короткая инструкция для человека (не для Claude Code): как разово открыть доступ к
локально запущенному приложению — например, чтобы члену семьи протестировать с телефона —
и как закрыть его обратно. Ничего из проекта читать не нужно, всё необходимое здесь.

## 1. Предпосылка: приложение уже запущено локально

Окружение должно быть поднято:

```bash
./packages/docker/dev-up.sh
```

Проверьте, что приложение отвечает — откройте в браузере <http://localhost:3000> и убедитесь,
что открывается экран входа. Наружу нужен только один порт — **3000** (frontend). Backend
отдельно пробрасывать/туннелировать не нужно: браузер обращается к API через тот же адрес,
что и сайт.

## 2. Установка `cloudflared` (один раз)

```bash
brew install cloudflared
```

Если `brew` не установлен — сначала поставьте Homebrew с <https://brew.sh>.

## 3. Запуск туннеля

Именно на порт **3000** (frontend), не на backend:

```bash
cloudflared tunnel --url http://localhost:3000
```

Терминал с этой командой должен оставаться открытым всё время, пока нужна ссылка.

## 4. Где взять ссылку

В выводе команды `cloudflared` появится строка вида:

```
https://random-words-1234.trycloudflare.com
```

Это и есть публичная ссылка — её нужно скопировать и отправить тому, кто будет тестировать.

## 5. Проверка перед отправкой

Прежде чем отправлять ссылку, откройте в браузере адрес **`<ссылка>/api/health`**,
например:

```
https://random-words-1234.trycloudflare.com/api/health
```

Должен вернуться ответ:

```json
{ "status": "ok" }
```

Если ответ пришёл — значит и сайт, и API доступны снаружи, ссылку можно отправлять. Если
нет — проверьте, что `dev-up.sh` действительно поднял приложение и <http://localhost:3000>
открывается локально.

## 6. Ограничения (важно понимать)

- Ссылка **временная**: она пропадает, как только вы нажмёте `Ctrl+C` в терминале с
  `cloudflared` или Mac уйдёт в сон / потеряет сеть.
- При каждом новом запуске команды из шага 3 адрес будет **другим** — старая ссылка
  перестанет работать.
- Это одноразовый quick-tunnel для быстрого теста, **не продакшен-туннель** и не постоянный
  адрес. Для постоянного доступа нужна отдельная настройка (именованный туннель, домен) — она
  выходит за рамки этой инструкции.

## 7. Как остановить

Вернитесь в терминал, где работает `cloudflared`, и нажмите `Ctrl+C`. После этого ссылка
сразу перестаёт работать, никакой порт наружу больше не открыт. Само приложение при этом
продолжает работать локально — чтобы остановить и его, используйте `./packages/docker/dev-clean.sh`.
